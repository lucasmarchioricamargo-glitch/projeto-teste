## Dev Notes

### URLs estáveis — boas práticas

| Opção | URL típica | Estabilidade | Manutenção |
|---|---|---|---|
| Google Drive público | `drive.google.com/file/d/{ID}/view` | Alta (não expira) | Baixa |
| Cloudflare R2 | `cdn.residenciapro.com.br/mini-mapa-{prof}-2026.pdf` | Muito alta | Média |
| GitHub LFS / Raw | `raw.githubusercontent.com/.../mini-mapa-{prof}.pdf` | Alta | Baixa, requer repo público |
| Vercel Blob | `*.public.blob.vercel-storage.com/{file}` | Muito alta | Baixa, requer Vercel project |

### Estrutura sugerida de `urls.json`


### Documento para Camila — esboço

> # Como funciona o Mini-Mapa
>
> 1. Você posta um carrossel sobre residência (sua rotina normal)
> 2. No último card, adiciona: "Comenta `MAPA{PROFISSÃO}` aqui embaixo que eu te mando!"
> 3. ManyChat detecta automaticamente e responde no DM com o PDF certo
> 4. Você não precisa fazer nada extra. Só lembrar do CTA
>
> **Palavras-gatilho disponíveis:**
> - `MAPAENFERMAGEM` → Mini-Mapa de Enfermagem
> - `MAPAFISIO` → Mini-Mapa de Fisioterapia
> - `MAPANUTRICAO` → Mini-Mapa de Nutrição
> - `MAPAPSICOLOGIA` → Mini-Mapa de Psicologia
> - `MAPA` → menu com as 12 profissões (use quando o post não for de uma área específica)
