## Taxonomia

| Código | Área |
|--------|------|
| PSI-CLINICA | Psicopatologia, diagnóstico, intervenções clínicas |
| PSI-SAUDE | Saúde Mental no SUS, RAPS, reforma psiquiátrica, saúde coletiva |
| PSI-TEORIA | Teorias psicológicas (Freud, Lacan, Rogers, Jung etc.) |
| PSI-AVALIA | Avaliação psicológica, documentos, DCNs |
| PSI-ETICA | Código de Ética, bioética, sigilo |
| PSI-ORGAN | Psicologia organizacional, saúde do trabalhador |
| PSI-APS | APS, NASF/eMulti, SUAS, proteção social |

**Níveis cognitivos (NC):** M = Memorização · C = Compreensão · Ap = Aplicação · An = Análise
